# 🏠 House Price Prediction System

## 📌 Project Introduction
The House Price Prediction System is a web-based application designed to estimate house prices based on property size, number of rooms and location.

The application provides an interactive interface that helps users explore estimated property values and understand how nearby facilities can influence house prices.

## 🎯 Objectives
- To develop a user-friendly house price estimation website.
- To estimate property prices based on house size and location.
- To provide interactive location selection using maps.
- To display estimated prices and growth comparisons.
- To provide additional features such as EMI calculation and nearby amenities.

## 🛠️ Technologies Used
- **HTML5** – Web page structure.
- **React.js** – User interface development.
- **JavaScript** – Price calculation and application logic.
- **Tailwind CSS** – Website styling and responsive design.
- **Leaflet.js** – Interactive maps.
- **Babel** – JSX transformation.
- **Canvas Confetti** – Prediction result animations.

## ⭐ Features
1. House size and room input.
2. Location-based price estimation.
3. Interactive map and location selection.
4. Nearby amenities information.
5. EMI calculator.
6. Price growth comparison.
7. Voice input functionality.
8. Animated prediction results.
9. Responsive and modern user interface.

## ⚙️ How It Works
1. Open the House Price Prediction website.
2. Enter the house size.
3. Enter the number of rooms.
4. Select or enter the property location.
5. Generate the price estimation.
6. View the estimated price and additional information.

**Note:** The current version uses predefined pricing formulas and location-based adjustments. It does not use a trained machine learning model.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run it using the Live Server extension.
5. Make sure you have an internet connection to load the external libraries and map resources.
